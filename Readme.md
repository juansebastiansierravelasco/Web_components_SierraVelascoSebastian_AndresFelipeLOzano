
# Actividad evaluativa: Web Components, HTML Templates y Frameworks

* **Integrantes:** Juan Sierra y Andrés Lozano.
* **Caso elegido (Práctica):** Agenda Cultural.

## Cómo probar el componente

1. Clona este repositorio o descarga los archivos.
2. Abre el archivo `index.html` directamente en tu navegador web (Google Chrome, Firefox, Edge o Safari).
3. Verifica que se visualicen correctamente las 3 tarjetas de las mascotas con sus estilos independientes, atributos dinámicos y notas mediante slots.

## Declaración de uso de Inteligencia Artificial

Para el desarrollo de esta actividad se utilizó asistencia de Inteligencia Artificial (IA) como apoyo de consulta y estructuración de conceptos teóricos y sintaxis base de Web Components nativos. Todo el contenido teórico de la investigación fue redactado, comprendido y adaptado con nuestras propias palabras, y el código de la práctica fue analizado y probado línea por línea.
